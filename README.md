## Our Products

### AegisLog

**Understand your logs. Review the evidence. Decide what needs attention.**

AegisLog is a free, open source, terminal based defensive log investigation tool. It analyzes supported log files and accessible Windows Event Logs, Linux journald and Docker telemetry while handling sources as read only.

It supports file and folder investigations, live monitoring of one or multiple sources, grouped findings, investigation timelines, saved cases and local HTML reports. Findings include evidence and recommended review steps to help users investigate authentication activity, operational failures and selected security signals.

**For:** system administrators · developers · security analysts · students

**Processing:** local and deterministic  
**License:** MIT  
**Current release:** v2.1.17  
**Distribution:** standalone Windows executable, Windows ZIP and Python packages

AegisLog has no browser dashboard or remote AI dependency. Findings are investigation leads rather than proof of compromise. Coverage depends on supported formats, source permissions and evidence limits. The Windows executable is unsigned; matching SHA-256 checksums accompany release assets.

### Sentrix

**Review Python code with clearer findings and professional reports.**

Sentrix is a commercial Python code analysis workspace that combines Pylint, Bandit, Radon, Black and syntax validation in a local browser interface.

It brings together project uploads, code quality checks, security findings, complexity metrics, project history and downloadable reports. Its standards guidance provides context where applicable; mappings do not establish certification or legal compliance.

**For:** Python developers · reviewers · development teams

**Current release:** v1.0.0 FINAL  
**Distribution:** portable Windows package  
**Source:** proprietary commercial software

## How We Engineer

**Evidence before claims**  
Our tools explain observations and limitations so users can make informed decisions.

**Security throughout development**  
Testing, static analysis, dependency checks and careful input handling support our development process.

**Releases that can be checked**  
AegisLog uses automated package and Windows executable checks, reviewed asset digests, matching checksums and protected repository updates.

**Readable workflows**  
Installation, navigation, findings and reports should help users complete a task without unnecessary complexity.

**Learning through delivery**  
We apply continued study through labs, working software, testing and documented releases. Coursework is described as training, not vendor certification unless separately awarded.
